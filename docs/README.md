# Índice da Documentação

## Documentação canônica

A documentação vigente do produto está em [`v2/`](v2/README.md). Ela considera
o mockup funcional em `style-system/` como contrato integral da aplicação.

## Documentação histórica

Os arquivos numerados diretamente nesta pasta, os contratos R1-R7 e as decisões
anteriores à ADR-D014 registram a evolução da V1. Permanecem disponíveis para
auditoria, decisões técnicas e reaproveitamento, mas não podem reduzir o escopo
funcional definido para a V2.

- `SDGB.md`: diretrizes normativas.
