# TU-IMG — identidade visual de turmas e educadores

Entrega autorizada em07/11/2026, separada do TU1-R3. Direção prévia UI/UX e Product Design: imagem junto ao título, edição somente para quem gerencia a turma, mesma escolha avatar/foto, arquivo/câmera/recorte/compactação; cancelar e falhar preservam a imagem anterior.

1. Catálogo36educadores adultos separado dos alunos; dados de avatar e fotos salvas preservados.
2. Catálogo36brasões originais medievais em pixel art para turmas.
3. API aditiva com imagem privada e versionada, autorização por alcance/perfil e auditoria; três campos com defaults compatíveis, sem backfill/exclusão.
4. Interface em desktop/celular, edição a partir da imagem, reutilizando preparo de foto aprovado.
5. Revisão independente, regressões, CI e publicação somente na homologação após TU1-R3. Produção excluída.

Assets PNG gerados pela ferramenta nativa image_gen e copiados para o repositório. Cada catálogo é um único atlas6×6 usado por CSS, sem36downloads. Alunos continuam usando estudantes-v1.png; profissionais utilizam educadores-v1.png; turmas usam brasoes-v1.png.
