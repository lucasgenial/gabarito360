# DESIGN SYSTEM GOVERNAMENTAL BRASILEIRO (DSGB)

Versão: 1.0

Baseado no Manual de Marca do Governo Federal (2026)

---

# OBJETIVO

Este documento define padrões visuais, componentes, acessibilidade, usabilidade e identidade visual para sistemas governamentais brasileiros.

Aplica-se a:

* Sistemas Web
* Aplicativos Android
* Aplicativos iOS
* Dashboards
* Portais Públicos
* Sistemas Administrativos
* Plataformas SaaS Governamentais

---

# PRINCÍPIOS

## Simplicidade

Interfaces devem ser intuitivas e autoexplicativas.

## Leveza

Evitar excesso de elementos visuais.

## Transparência

Informações públicas devem possuir destaque.

## Acessibilidade

Conformidade WCAG 2.2 AA.

## Responsividade

Mobile First.

## Consistência

Todos os sistemas devem compartilhar os mesmos padrões.
